# Publicar no GitHub

1. Entre na sua conta e crie um repositório chamado `alimento-em-dia`.
2. Escolha a visibilidade conforme a orientação da faculdade; se privado, conceda acesso ao tutor.
3. Na opção de enviar arquivos, arraste o conteúdo da pasta extraída, preservando static/, docs/ e tests/. Não envie somente o ZIP.
4. Confira a lista e grave a publicação com uma mensagem como `Adiciona aplicação e documentação`.
5. Abra README.md e confira os links e diagramas. Copie o endereço do repositório para a entrega.

O GitHub identifica a conta e a autoria dos commits. O nome do repositório não precisa conter GPT ou ChatGPT. Não atribua commits a pessoas que não participaram nem remova autoria exigida pela instituição. Consulte as regras do curso sobre auxílio de ferramentas.

Nunca publique banco de dados, backups, senhas, tokens de conta ou respostas pessoais dos avaliadores sem consentimento. O .gitignore protege arquivos em operações Git, mas não substitui a conferência em uploads manuais.
